# Information on old files

- This folder (`./old/`) contains a series of scripts that were used by another repo from an internal ex-researcher in our group to produce another paper. It also eventually led to the initial idea of the SPI-SPI meta-feature by correlating off-diagonal entries for every pair of $K$ adjacency matrices, which has now evolved to surpass the content that the scripts entail. These files similarly operate over the 1,053 multivariate time series database, for which the original user had computed an (old) version of pyspi on.
- The scripts here were (loosely) used for post-processing and visualizations that are mostly NOT pertinent to our goals or repo. They largely address a different problem to what we are motivated by. However, some scripts overlap with what we desire (as components of the current repo are in reproducing some draft internal results that were made by this researcher), which can be pinned down later.
- Since this is old work, the code is likely not optimal, and the idea may not be conceptually refined yet. You may identify the core function, purpose, limitations, intentions, and irrelevant/outdated functions, packages, or scripts (e.g. pickle used instead of .npz).
