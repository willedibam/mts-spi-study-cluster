# Post-pilot mechanism checks

Declared after the fresh pilot results: zPLS joint-shift BA10/20/40=.8883/.96/.98,
richm=.6433/.74/.8083, normalizedshapes=.6533/.70/.7367. Fusion improves each
marginal baseline. Direct phase/envelope agreement=.9633/.9633/.98; a specialist
already solves the target. These are useful scoped results, not global neural
superiority or clinical validation. The original encoder and random controls
remain near chance; this does not bound other neural designs.

Use existing data/MPIs and fixed source cohorts/readouts. No new generator or
larger data collection is justified for these checks. Their role is to explain
which information the representation uses, not to select the best configuration
for the reported original pilot.

1. Three independent per-SPI dyad permutations (seeds503/509/521) remove
   cross-SPI correspondence while preserving each SPI's edge-value multiset,
   symmetry/reciprocity, and z's validity mask. Verify those properties for every
   record, plus common-permutation invariance. Refit zPLS with the same source
   labels/tuning. Permuted MPI collections need not correspond to realizable
   raw recordings; this is a representation mechanism intervention.
2. Two fixed catalogue ablations, specified from the generator's two coupling
   modes rather than a test-set importance ranking: remove every coordinate
   involving a power-envelope-correlation SPI (names starting `pec`); retain only
   cross-family coordinates pairing `pec` SPIs with phase-locking-value SPIs
   (names starting `plv_`). Use PLS1/2/4 and the same labels. These test the role
   of explicit amplitude-envelope measures and a small mechanism-informed panel.
   They do not establish that other SPI pairs contain no relevant information.

Compare original and reduced observations at all label budgets. Report all three
null draws separately; they are not additional independent datasets. Keep all
original full-catalogue results. A tailored small panel matching or beating fullz
is an explanatory specialist, not a replacement claim for the frozen catalogue.
