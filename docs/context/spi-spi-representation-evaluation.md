## Scientific contract and claim boundary

- Operational full catalogue is **289 SPIs** in `configs/pyspi/benchmarked_p90.yaml`, not the expensive unrestricted `full.yaml`. User confirms p90 is affordable with dataset-level Gadi parallelism; M<=32 is sufficient initially.
- Primary `unified_ordered_v3` (`src/spi_spi_contract.py`, `src/process_features.py`) vectorizes all ordered off-diagonal entries, both directions, then correlates aligned SPI pairs: exactly 41,616 coordinates. Invalid values stay NaN with masks; schema and content/provenance hashes are frozen. Training-only filtering/imputation/scaling is separate.
- z retains cross-SPI edge correspondence but loses edge incidence, locations, per-SPI means and positive scales. It is invariant to common channel relabelling, arbitrary common edge permutation and simultaneous MPI transposition. It can respond to interaction properties without identifying a mechanism or causal direction uniquely. Channel subsampling/mixing and duration changes have no general invariance guarantee.
- Valid Pearson/Spearman blocks are Gram matrices, generally PSD, rank <=min(K,M(M-1)-1), not SPD. For M2, symmetric SPIs give invalid correlations and valid directed pairs are +/-1. Unscaled Euclidean z is Frobenius matrix distance up to sqrt(2). MI similarities need not be PSD. No empirical gain from new matrix geometry is established.
- Deterministic z=f(X) cannot contain information inaccessible in principle from raw X. The defensible learning claim concerns how efficiently specified learners extract useful information under label/observation constraints. Fixed extraction and learned readout are distinct stages.
- [Cliff2023](https://www.nature.com/articles/s43588-023-00519-x) already compares SPI relationships, including record-wise correlations subsequently averaged. Novelty must concern useful record-level representation behaviour, not matrix correlation itself. [HCGA](https://pmc.ncbi.nlm.nih.gov/articles/PMC8085611/) and bilinear pooling are adjacent precedents. [Study design](../spi-representation-learning-study.md) records the detailed literature and geometry reasoning.
- Variable-channel neural learning already exists (shared temporal encoder/message passing, BIOT, UniTS, REVE). Shape compatibility is insufficient novelty. The user's marmoset example is speculative context, not the paper's focus; no real-data advantage or dataset access is established.
- User supports purposeful exploration but rejects an ever-growing benchmark grid or universal-optimality criterion. Specialist success does not invalidate a generic descriptor. User explicitly authorizes justified larger runs, alterations or stopping while asleep; preserve negative results and do not change generators solely to force a win.
- User belongs to the Cliff et al. research group; frame this as a continuation while distinguishing the contribution. Journal criteria are broad guides, not exact templates. One versus two papers remains open: separate only if the learning work has an independent substantive claim. Pearson's favourable bias-variance tradeoff is a hypothesis, not established by coarse compression or many feature pairs; richer learned pooling need not improve finite-data performance or destroy interpretability.
