## Verified legacy behaviour and defects

- Explicit `legacy_symmetrized_v1` remains reproducible. For each MPI it uses the strict upper triangle of `(A+A.T)/2`; `build_spi_spi_features` correlates these edge vectors and flattens SPI-pair upper triangles. MPI diagonals and SPI self-pairs are excluded.
- Consequently, direction is discarded by default and a purely antisymmetric MPI becomes zero. Legacy `--split-directed` retains fixed-label upper/lower vectors, but is not invariant to arbitrary channel relabelling.
- Legacy `nonfinite_policy="zero"` conflates undefined correlation with zero association and can break the correlation-Gram interpretation. Its corpus-wide `std >= 1e-8` filter makes the schema depend on all analysed rows, including test rows.
- Legacy cache identity omitted variance threshold, contract version, pyspi configuration/version/normalization, source hashes and repository revision. Old caches are therefore evidence for their archived calculation, not automatically interchangeable with current computations.
- Directed flags include pyspi `directed`, `asymmetric` and `antisymmetric` SPIs. PySPI v3 also transposed six directed spectral SPIs, so estimator version and source/target convention are material provenance.

## Frozen v2 feature contract — implemented and tested

- Core commit `77ba664` introduced `src/spi_spi_contract.py`; final historical analysis alignment is `fbbb903`. Reproduction and directional sensitivities explicitly request `direction_preserving_v2`.
- For SPI MPI `A_a`, `z_sym[a,b] = corr(u_a,u_b)`, where `u_a` is the strict upper triangle of `(A_a+A_a.T)/2`. This exactly reproduces the legacy NaN-valued subspace for Pearson/Spearman and valid histogram-MI cases.
- Let `v_a=(A_a[i,j]: i != j)` in C row-major order. `z_dir` contains: parallel `corr(v_a,v_b)` for every SPI pair involving at least one directed SPI; reverse `corr(v_a,v_b^T)` for each directed–directed pair; and self-reciprocity `corr(v_a,v_a^T)` for every directed SPI. Undirected–undirected duplicates are omitted.
- With `K` SPIs and `D` directed SPIs, `dim(z_sym)=K(K-1)/2` and `dim(z_dir)=DK`. Both are invariant to a common channel permutation. Transposing one directed MPI swaps its directed–directed parallel/reverse relations; pure antisymmetry remains visible through reciprocity `-1`.
- The canonical artifact stores `X_sym` and `X_dir` once. `z_aug=[z_sym,z_dir]`; block balancing is an optional downstream fit, not part of feature identity. It scales each block to unit total development variance without feature whitening.
- Undefined values remain NaN with validity masks and per-SPI reasons. V2 performs no corpus variance filtering. Downstream imputation, validity/variance selection, centring and any balancing are fit on development rows only (`src/spi_spi_analysis.py`).
- V2 schema records block, relation and SPI names plus SHA-256. Cache identity includes contract/metric/options, ordered SPI/direction hashes, input content hashes, pyspi config/version/normalization, builder hashes and repository state; loading revalidates identity, schema, dimensions and masks. Older metadata is explicitly provenance-incomplete.
- Tests in `tests/test_spi_spi_contract.py`, `tests/test_feature_artifact_contract.py` and `tests/test_spi_spi_analysis.py` cover exact symmetric reproduction, permutation/transpose laws, antisymmetry, undirected equivalence, diagonal exclusion, NaN handling, schema/cache provenance, development-only transforms and block balancing. `python -m pytest -q` passed 58/58 on 2026-08-24.

## Representation-learning assessment — 2026-09-06

- Research advice, not an adopted experimental protocol: test label efficiency and retained task performance under specified observation shifts; deterministic `z=f(X)` cannot contain target information inaccessible in principle from `X`. Separate independent training records/subjects `N`, channels `M`, duration `T`, pretraining exposure and compute. A fixed feature catalogue is feature extraction; learning a map/readout over it is a separate step.
- Novelty boundary: [Cliff et al. 2023, Supplement S3.1](https://arxiv.org/html/2201.11941v2) already computes per-record absolute Spearman correlations between off-diagonal MPI entries, then averages across records. The proposed contribution must establish utility of retaining per-record SPI relationships as a representation, rather than novelty of matrix correlation itself. [Bilinear pooling](https://openaccess.thecvf.com/content_iccv_2015/html/Lin_Bilinear_CNN_Models_ICCV_2015_paper.html) and [HCGA](https://pmc.ncbi.nlm.nih.gov/articles/PMC8085611/) are adjacent precedents.
- Neural variable-channel learning exists: [Brüsch et al. 2023](https://arxiv.org/html/2307.09614v2) uses a shared temporal encoder, message passing and mean readout (six-channel PC18 to two-channel SleepEDFx); [BIOT, NeurIPS 2023](https://proceedings.neurips.cc/paper_files/paper/2023/hash/f6b30f3e2dd9cb53bbf2024402d02295-Abstract.html), [UniTS, NeurIPS 2024](https://papers.nips.cc/paper_files/paper/2024/file/fe248e22b241ae5a9adf11493c8c12bc-Paper-Conference.pdf), and [REVE](https://arxiv.org/abs/2510.21585) rule out a general first-capability claim. Shape compatibility does not establish statistical transfer for either approach.
- Mathematical limitation checked directly against `build_unified_feature_values`: for `M=2`, symmetric MPI vectors are constant/invalid and any valid directed Pearson pair is exactly ±1. More generally, a valid Pearson correlation block has rank at most `min(K,M*(M-1)-1)`; edge pairs share channels and are not independent replicates. Thus two-EEG-channel SleepEDFx is unsuitable for current pure `z`, despite being a useful neural precedent.
- Pooling-stage deductions: Pearson `z` discards each MPI vector's mean and positive scale and is invariant to a shared arbitrary permutation of edge positions, not only node relabelling. It retains cross-SPI edge alignment but not graph incidence; this does not assert every permuted collection is realizable by a raw MTS. Channel subsampling, rereferencing and sensor mixing have no general invariance guarantee.
- Verified local `confirmation-results.json`: symmetric accuracy `.99127`, combined pooled baseline `.97659`, symmetric hard mAP `.81767`, best pooled mAP `.76738`, symmetric cell leakage `.57897`. These are v2 symmetric results, not validation of the current unified v3 contract. Held-cell training still sees each individual `M` and `T` value elsewhere; this is not unseen-size extrapolation.
- Critical proposed comparison: mean/scale/quantile summaries from the same complete SPI catalogue, then `z`, their concatenation, and a learned set/graph aggregation of the same MPIs. Existing `src/cross_mt_transfer.py::pooled_dependence_features` uses contemporaneous/lag-one correlations and correlation-spectrum summaries, not the full catalogue. This comparison controls catalogue breadth but does not identify an alignment mechanism by itself: corr(V,V²) also encodes third/fourth marginal moments of one statistic. Richer marginal descriptors, nonlinear readouts and algebraic-duplicate sensitivity are needed before the stronger organization claim; see the study attribution section.
- Candidate public pilots: [NeuroTycho anesthesia/sleep](https://wiki.neurotycho.org/Anesthesia_and_Sleep_Task_Details) (four macaques, drug/state experiments; small independent sample, induced subset variation is only a robustness test); [CHB-MIT](https://physionet.org/content/chbmit/1.0.0/) (annotated seizures; patient grouping must join chb01/chb21); [TUSZ](https://isip.piconepress.com/projects/nedc/html/tuh_eeg/) (larger clinical validation, access request). User clarified that marmoset work is speculative context, with no identified data, and is not the paper's present focus; do not redirect the project around neuroscience. No real-data advantage or publication-tier claim is established.
