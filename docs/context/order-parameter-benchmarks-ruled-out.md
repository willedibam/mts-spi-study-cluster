## Candidate portfolio and literature reserves

- Superseded 2026-09 portfolio: Miller–Huse and Stuart–Landau as headline systems, the 1-D quadratic CML as a secondary/negative stress test (keep as limitation or appendix, do not run its confirmation), driven kinetic Ising as backup, and Vicsek, contact process, CGLE and neural models deferred. The [candidate selection](../../research/inference/benchmarks/notes/candidate-selection-260910.md) superseded blanket Vicsek deferral; the [candidate evaluation](../../research/inference/benchmarks/notes/candidate-evaluation-260910.md) holds the comparative table, larger-M cost scoping and no-cosmetic-grid-rerun guidance. Current position: SL, DZ, MH and Kuramoto suffice, with CML2D a viable additional canonical example; no forced Vicsek or new Ising-family implementation.
- Periodically driven kinetic Ising: the strongest formal dynamic-Q literature, with cycle-averaged magnetization and explicit dynamic phase diagrams ([PRL 81, 834](https://doi.org/10.1103/PhysRevLett.81.834); [PRB 52, 6550](https://doi.org/10.1103/PhysRevB.52.6550)). It is genuinely stochastic dynamics, unlike the deleted static Ising assay, but implementation is conditional on the user revising the broader Ising exclusion.
- ZGB with CO desorption: published (CO feed y, desorption k) phase diagram with a discontinuous active/high-CO line; Q = theta_CO, and k > 0 removes the absorbing CO-poisoned state. Endpoint estimates are method-dependent: k_c ≈ .0406 from coexistence finite-size scaling ([PRE 71, 031603](https://doi.org/10.1103/PhysRevE.71.031603)) versus (y_c, k_c) = (.554, .064) from a 2018 time-dependent pseudocritical analysis ([PRE 98, 032113](https://doi.org/10.1103/PhysRevE.98.032113)); the planned k = .02 cut is below both. Exact random-sequential pilots reproduce sharp hysteresis: at L=64 empty/high-CO starts jump over .534–.535/.528–.529; at L=100 with 5k-MCSS burn and record over .534–.535/.530–.531, bracketing the published coexistence region. Maximum start-state gap .87 and L=100 coverage block-range p95 .85, because metastable switching contaminates finite records. Not p90-ready: bimodality, finite-L scaling and an explicit branch/coexistence estimand are required. Evidence `research/inference/candidate_search/zgb_desorption_physics_scout.py` and `data/order_parameter/zgb_desorption_physics_scout*/`.
- Hamiltonian mean-field rotators: magnetization vanishes continuously at exact U_c = 3/4 (T_c = 1/2) ([PRE 52, 2361](https://doi.org/10.1103/PhysRevE.52.2361)); published finite-N comparisons use N = 100 and 1000, so M=N=32–100 is a defensible rounded precursor. Severe quasistationary and initial-condition dependence makes an equilibrium protocol and relaxation audit mandatory. Empirical p90 scaling predicts about 57 min/row at M=50/T=1000 versus 23 min at M=32; use a small nested pilot, not a full bank. Coupled Rössler networks give an exact finite-dimensional synchronization boundary via master-stability analysis ([PRL 80, 2109](https://doi.org/10.1103/PhysRevLett.80.2109)) but use an operational order quantity and overlap Kuramoto/SL.
- Exact Kaneko-CML revisit (1-D diffusive ring `x_i'=(1-eps)f_alpha(x_i)+eps/2[f_alpha(x_{i-1})+f_alpha(x_{i+1})]`, not the 2-D Marcq CML): the strongest verified target is the Gade–Sahasrabudhe persistence phase diagram ([PRE 87, 052905](https://doi.org/10.1103/PhysRevE.87.052905)), whose lower critical curve separates zero persistence/moving defects from a modulo-two frozen long-range antiferromagnetic state. Their logistic mu maps to ours by alpha = mu(mu−2)/4 with eps preserved, giving critical points (alpha, eps) = (1.5725, .015), (1.640625, .045), (1.71, .065), (1.8816, .104). Persistence is the published order parameter; defect density or staggered order is a complementary instantaneous observable. This is asymptotic coarsening (N=8000 with 400k transients for the plane, N=50000 for critical scaling), so a physics-only size/time gate is mandatory. At alpha=2, later exact-ring work ([Chaos Solitons Fractals 2023](https://doi.org/10.1016/j.chaos.2023.113510)) finds zigzag ordering for eps .124–.164 with phase-defect density; Lacasa et al. ([Sci. Rep. 5, 15508](https://doi.org/10.1038/srep15508)) give an N=200 intercept (FDT < .12, defects/STI .12–.15, periodic pattern selection .16–.20, FDT > .20) with visibility-network order parameters that are too close to SPI–SPI to be an independent headline truth. Pattern-selection-to-FDT has no verified canonical scalar; never retrofit one onto the old eps=.3, alpha 1.6–2.0 path. A claim-bearing run needs a large ring and a size/time ladder; low M=N is a finite-size/commensurability diagnostic only.
- Inertial noisy Kuramoto has canonical R and a first-order/hysteretic surface ([PRE 89, 022123](https://doi.org/10.1103/PhysRevE.89.022123)) but is too close to the existing synchronization baseline; Vicsek polarization needs very large populations and long band-coexistence runs. Both are backups. Chua crisis and Lorenz intermittency are literature-backed, untried three-state contenders (candidate evaluation note).
- Do not lead with homogeneous Brusselator Hopf or Swift–Hohenberg onset: post-transient channels become identical or stationary, so the MTS/SPI problem degenerates without added noise or heterogeneity. Do not lead with CGLE phase/defect turbulence: the boundary is finite-time and nucleation sensitive. The contact process has canonical active-site density but an all-zero absorbing phase that degenerates p90 inputs.
- Application bridges are a separate tier: Sompolinsky–Crisanti–Sommers neural fixed-to-chaos, Brunel E/I spiking, Epileptor/Jansen–Rit seizure-like bifurcations, power-grid swing synchronization loss. None is a faithful generic proxy for real data; there is no accepted scalar consciousness order parameter and no universal clinical seizure order parameter across onset types.
