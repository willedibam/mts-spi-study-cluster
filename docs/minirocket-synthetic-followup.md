# MiniRocket/ridge on the synthetic transfer core

Declared before fitting on 2026-09-12, after the InceptionTime results. This is one user-authorized conventional fixed-feature comparator, not fresh confirmation or a new benchmark grid. The question is whether a generic convolutional feature transform with a simple classifier already exposes the same co-organization target efficiently.

Reuse the hash-verified source and three target packs in `results/inceptiontime_followup_260911`: unchanged float32 recordings, M=16, T=1000; the nine original source cohorts/budgets (10/20/40 total labels, three disjoint 40-label pools), and original/faster/direct-mechanism targets with 200 independent masters each. No target-derived preprocessing, extra source realizations, per-record normalization, pyspi extraction, reduced-channel adapter or generator changes.

Use aeon 1.5.0 `MiniRocketClassifier`, 10,000 requested kernels (9,996 realized features), 32 maximum dilations, two CPU threads and transform seeds 11/23/47. Its native pipeline is multivariate MiniRocket, `StandardScaler(with_mean=False)` and `RidgeClassifierCV(alphas=logspace(-3,3,10))`. Keep its native source-only internal ridge selection instead of replacing it with the earlier two-fold neural or logistic selection. The transform/scaler are fitted on the source cohort before internal ridge CV; this is the conventional pipeline's recipe, not a fold-isolated transform audit or identical tuning protocol to the earlier readouts. No candidate menu of normalizations, feature layouts, heads or augmentations.

Fit all 27 source models before opening any target pack. Save model/manifest/code/protocol hashes, exact source IDs, chosen alpha, transformed feature count, source predictions and runtime. Resume validates identities and skips completed source fits. Default classifier decisions and signed decision scores determine BA and AUROC; these are not calibrated probabilities, so do not invent Brier scores. Primary aggregation is mean metric over three source cohorts and three transform seeds, with every individual row retained; no ensemble. Target masters are shared across fits and must not be counted repeatedly as independent systems.

Verify serialized source predictions, independent rank-based AUROC and class-wise BA against a separate metric implementation, and sampled target feature/model replays. Audit source IDs/splits and frozen source report hashes against the completed evaluation. Report all budgets, targets and selected-alpha boundaries. Interpret alongside z, rich summaries, learned SPI pooling and the direct specialist; a favourable result does not establish superiority over an entire library or every fixed-feature map.

Run locally in the existing `.venv-neuro-baselines` environment: `PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 .venv-neuro-baselines/bin/python scripts/run_minirocket_synthetic_followup.py`. Existing small source cohorts and compact target packs do not justify a Gadi submission. Authoritative output root: `results/minirocket_synthetic_followup_260912`.
