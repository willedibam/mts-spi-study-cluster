# Datasets for a character-of-dependence result outside anaesthesia (24 November 2026)

Scope: a metadata and literature screen, no pyspi and no waveform downloads. It is a delta on the [4 November screen](../research/representation/dataset_candidates/candidates.md), re-rated against the frozen protocol the MI-pair result now uses (`research/representation/atlas/mi_pair/preregs/claar-prereg.md`): 10-s windows (T ≈ 1000 at 100 Hz) with ≥ 10 stationary windows per state per unit, 17–30 channels, three joint spectrum-final IAAFT draws per window, a same-state split-half null in SDs across units, and a sign test over ≳ 15 units. Neural candidates are in scope (user, 24 November); non-neural ones are a plus.

Labels: **[V]** checked this session against the data's own metadata, official page or abstract; **[I]** inference; **[U]** unverified.

## Kill tests applied before anything else

1. **Sustained states.** Both states must be stationary across the window. Onset-type contrasts (substorm onset, congestion build-up, seizure evolution) reject IAAFT for drift, which is the classic false positive in the [reading rules](interpreting-spi-pairs.md).
2. **Timescales per window.** Count the characteristic periods or correlation times in a window, not the samples.
3. **Null scale.** Each unit needs ≥ 2 separated same-state segments, and there must be enough independent units.
4. **Geometry.** Sensors must be separate subsystems with heterogeneity across pairs. Gridded or closely spaced smooth fields sit at ceiling.
5. **Defensible axis.** Map priors only to Gaussian vs kNN MI (normal-scored, beyond IAAFT), `ppc|dswpli` or `cohmag|icoh` against zero-phase and stationary nulls, `pec` vs |γ|², band or mediation. Never map to Pearson–Spearman (the form axis failed). A lag result is linear timing: it survives a zero-phase null, and IAAFT reproduces it.

## Top three, in more detail

**1. HUP ds004100.** The contrast that passes every kill test is spatial, not temporal: in the same stationary interictal run, compare z(Gaussian MI, kNN MI) on SOZ-incident edges with size-matched non-SOZ edge sets. Edge subsets are legal for the MI pair, because both statistics are bivariate and unconditioned. Run 1 against run 2 sets the null. Units are patients, so a sign test over ~50. Each 300-s run gives 30 windows of 10 s at M ≈ 60, which beats the Claar design. The risk is that SOZ excess is spike-driven. The existing transient cut and normal-scoring separate that, and a spike-driven result would still be a statement about joint bursts, not coupling form. Ictal vs interictal (b) is secondary: seizures chirp, so only late, rhythmic ictal windows are near-stationary. It is the same MI axis as anaesthesia, so it adds a field (pathology) but not a new axis.

**2. Raw 30-s PeMS corridors.** This is the one non-neural system where the predicted character change is quantitative and independent of the data. In congestion, pair (i, j) should lag by d_ij / c with c ≈ −15 to −20 km/h; in free flow, lag ≈ 0 at this resolution (1 km at 100 km/h is 36 s, about one sample). Lag grows with distance, so it is heterogeneous across pairs, which is what z reads. At 0.5-mile spacing [U] adjacent lags are about 3 min (≈ 6 samples), and a 3-h core spans roughly 10–45 wave periods [I]. Units are corridors, with replicate weekdays per corridor. The result would be linear timing that survives zero-phase and stationary nulls, while IAAFT reproduces it by construction. That makes it a validation against known physics, not a non-Gaussian discovery, which agrees with the 4 November verdict. Open items: the Clearinghouse's 30-s product name and file layout [U], detector spacing per corridor [U], and selecting congested-core windows without peeking at z.

**3. FAIR-MAST.** Access and an automatic H-mode label were verified this session. It is the most novel field, and coil geometry gives a by-design phase pattern. Shots are short and evolving, ELMs act as a shared gain, and the licence, sampling rates and flat-top durations are unverified. It needs one shot inspected (spectra, flat-top length, ELM rate) before any protocol is frozen.

## What changed since 4 November

- The protocol's null and unit requirements now decide the ranking, and the MI pair is the best-validated axis. That promotes HUP, an open iEEG set with an SOZ prior from the surrogate tradition, over the scalp IQ and age cohorts.
- MAST is new.
- The 5-min benchmark traffic sets are now rejected on arithmetic; raw 30-s data is required.
- The 4 November bottom line still holds: no non-neural candidate is a clear non-Gaussian discovery case. Traffic is physics validation of a timing axis.
