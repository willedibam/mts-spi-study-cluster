# Electronic-oscillator pilot

Question: which relationships between dependence measures change along a measured coupling sweep, and can those changes be explained through the underlying channel pairs? This is an exploratory physical application, not a classification benchmark or confirmation of a thermodynamic phase transition.

## Scope

- Start with the hybrid ER dataset [17451096](https://zenodo.org/records/17451096); use the companion small-world dataset [17451530](https://zenodo.org/records/17451530) for transfer if the first pilot is informative. - First inspect nine evenly spaced coupling settings, preserving all channels and the full recording duration. Test anti-aliased polyphase resampling to T=2,000, 5,000 and 10,000. Choose the smallest adequate T; no raw striding, silent truncation or envelope-only substitution. If no full-duration option passes, reassess justified shorter windows or abandon this bank.
- Assess per-channel spectra and waveform reconstruction, phase-coordination traces and edge profiles, amplitude-envelope edge profiles, and synchrony fluctuation/dwell behaviour. Numerical thresholds are screening tolerances, not universal guarantees of SPI equivalence. Validate representative accepted observations at the next higher sampling resolution with p90 where feasible.
- Begin extraction with two full-p90 observations and measure memory/runtime before a broader farm. The pilot is at most 29 settings per topology, starting uniformly and refining observed changes; refinements must resolve an observed sampling or interpretation question. No large biological datasets or channel-pair sampling work in this pilot.
- Centre eligible SPI–SPI coordinates without unit-variance scaling; use the ordered-edge Pearson contract. Missing/constant-feature handling must be explicit and fitted on development observations. Orient PCs by their largest absolute loading, without coupling or physical-reference labels. Treat PCs and embeddings as exploratory geometry; do not manufacture classes from coupling settings.
- Show the coupling trajectory, an independent physical coordination summary, eigenvalue spectrum, and compact boxed square galleries ranked by absolute PC1 loading. Retain the full model; optionally show a separate gallery excluding pairs with two classical-correlation endpoints. Inspect original MPI edge scatterplots for a few interpretable contrasts. Report feature coverage and loading stability; separate spectral sensitivity from mechanistic specificity.
- Split by physical recording/settings or topology, never claim windows from one sweep are independent experiments. With only one sweep per topology, validation is transfer/sensitivity evidence, not population replication.

### Minimal package plan and general allocation policy

Documentation only, as requested; no implementation or deployment. Start with **DistanceCorrelation upper-triangle evaluation only**, preserving the retained orientation/order and testing both bias variants, input mutation, constants/ties and exact old-path parity. This belongs in `pyspi/statistics/distance.py`, not a notebook or cluster monkeypatch. A separate second change is **exact batched KSG marginal counting**, including bounded temporal-exclusion correction, with independent brute-force count/radius tests and MI/CMI/direction/error parity. Leave adaptive joint search, wider distance whitelists, lagged Kendall, fast Dcorr and new spectral cache sharing as optional follow-ups justified by remaining profiles; they are not prerequisites for these two changes.

Only then consider opt-in package-level seeded parallelism: the same seed policy in serial and workers, independent of process identity/task assignment; stable cache-group membership/order; validated worker-local PSI setup; bounded caches, checkpoint identity and failure/result assembly. Compare repeats and worker counts before adoption. CPU allocation, affinity and per-node memory admission belong in the Gadi/Physics launchers. These pure-Python changes become available to editable installs after each host receives the tested source revision; deployment must occur between jobs, not by changing the shared editable checkout underneath active jobs. Keep the independently developed sampling branch separate until full-census equivalence and sampled/exact contracts pass after merging.

Let W be usable compute-worker/core slots, N pending recordings and k compute workers per active recording. Fixed groups run at most C=min(N,floor(W/k)) recordings, further constrained by per-node CPU packing and memory. Prefer k=1 when enough recordings are queued to occupy W; internal workers are attractive for a few long recordings, spare cores or lower single-record latency, if measured speed-up justifies memory and scheduling overhead. Each group dynamically consumes that recording’s SPI/cache tasks; existing n_jobs does not split channel-pair work inside one indivisible SPI. Dyad-chunk parallelism would be a distinct later change, especially relevant when one statistic dominates. When a recording ends, its group takes another queued recording; once the queue empties, finished groups remain idle. Neither completed groups nor workers waiting behind a final indivisible cache task automatically converge on another recording. A global recording×cache-group queue could enable that reuse but adds cache/data ownership, memory admission and result aggregation; defer unless measured tail waste warrants it.

Internal parallelism requires more than BLAS/OpenMP thread limits: disjoint verified CPU affinity, correct process initialization and estimator RNG, shared immutable inputs with process-local derived caches, memory bounds and faithful checkpoint/exception handling. A mostly idle controller need not reserve a dedicated extra core; its overhead still counts. Model memory as shared input plus controllers plus concurrent private caches/temporaries. Measure guarded peak R_k per recording and choose node concurrency no greater than min(floor(CPU_node/k),floor(RAM_budget/R_k)). CPU pinning avoids oversubscription but cannot prevent memory-bandwidth contention or memory exhaustion. The current serial 240GiB plan does not validate a multi-worker configuration.

Pair sampling and concurrency are complementary: sampling reduces the dyads evaluated; parallelism distributes the remaining work. Let D=M(M−1)/2 (496/4,950/11,175 dyads at M32/100/150). Use full enumeration when the required budget b approaches D; b cannot exceed the census under sampling without replacement. However, b is feature/distribution/tolerance-dependent, not determined by M alone, and global estimator fitting plus long T can remain expensive after sampling. Moderate M is not automatically cheap: these M28/T5000 smokes already took 3–4 hours. Existing [sampling evidence](../../../methods/pair_sampling/assessment.md) establishes numerical approximation, not universal budgets or extraction-speed gains; rare/near-constant profiles can require near-census coverage even at larger M. Prefer an explicit exact-versus-sampled mode with a future benchmarked crossover, rather than a hard M cutoff. Parallelism should remain available in either mode.

Screening tolerances: across the same full record, channel-p95 power above 0.4 of the new sampling frequency <=1%, waveform reconstruction NRMSE <=.05, PLV and envelope edge RMSE <=.03, Pearson edge RMSE <=.02, five-cycle-smoothed synchrony-trace RMSE <=.03, and difference in time above R=.8 <=.03. ## Character-axis calibration, 13 October

Instantaneous Pearson–Spearman z stays .99776–.99999 across all29 settings; Pearson–Spearman at the same 2 ms lag stays .99854–.99992. It is not a useful changing-nonlinearity marker in this bank. Pearson 2-versus-20 ms spans −.959→+.974, supporting the narrower descriptor “lag-profile agreement”; it is not a calibrated delay estimate. The broadband phase/envelope contrast reproduces in both five-second halves (23: .207/.159; 24: .992/.992), but fails a more important semantic check. Mean PLV remains above .999 in the filtered series, while envelope CV shrinks .214→.040/.012/.0025. These operations change the estimand and do not prove an artifact, but the near-perfect broadband relation cannot be claimed as correspondence between separate phase and amplitude processes.

An explicit counterexample reinforces this boundary: 28 phase-shifted copies of x_i(t)=cos(theta_i)+a cos(2 theta_i), theta_i=2π116t+phi_i, phi_i uniformly spaced on [−1,1], T5000/fs500. Waveform shape alone is sufficient for an apparently ideal axis.
