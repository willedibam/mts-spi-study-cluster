# Inference notebooks

New model figures should follow the concise [benchmark figure style](../../../../docs/benchmark-figure-style.md).

- `order-parameter-benchmarks-lean.ipynb` is the meeting-facing selection: Kuramoto, Stuart–Landau, Miller–Huse, quadratic CML, 2D logistic CML and Rössler, with equations, exact sweep grids, source links and three-control composites. It retains the 2D CML sensitivity/failure plots and excludes Desai–Zwanzig/Vicsek. Rebuild with `python -m research.inference.benchmarks.build_lean_order_parameter_notebook`; illustrative snapshot preparation is `python -m research.inference.benchmarks.prepare_lean_benchmark_snapshots`. The original comparison notebook is unchanged.

- `order-coordinate-three-systems.ipynb` is the compact visual narrative: CML2D independent confirmation with full-lattice portraits, the M24 varying-independent-sensor-noise locking example, and hardware r9 ER fit/small-world projection. It reads frozen results through `research.inference.benchmarks.three_systems` and `coordinate_features`, with matched top16 loading galleries and original-edge explanations; executing it validates source hashes and score replays and writes PNG/SVG/PDF plus a provenance receipt under `results/order-parameter-inference/three-systems-261015/`. No extraction or model refitting. This notebook uses Matplotlib’s built-in text/math rendering and requires no `latex` or `dvipng`; restart the kernel after updating the plotting helper.

- `order-parameter-composites_261021.ipynb` is the paper's section-4 composite: 2:1 locking as a full column (headline Q/q with in-axes MTS insets carrying physical glyphs, mean-|r| and mean-MPI glyphs, z_ab feature curves, edge planes) beside compact hardware, Stuart–Landau (fine) and CML2D panels. It includes trajectory and band versions, a Kuramoto alternative, a glyph gallery, hardware Q alternatives and notes on the open choices. Rebuild with `python -m research.inference.benchmarks.build_composites_notebook` (several minutes with LaTeX: it replays archives and regenerates glyph trajectories, no fitting). Figures and individually exported panels (SVG/PDF/600-dpi PNG) go to `results/order-parameter-inference/composites-261021/`.

- `order-parameter-benchmarks-baselines.ipynb` section 7 (hardware mean-|r| and mean-MPI baselines) is appended by `python -m research.inference.benchmarks.build_hardware_baseline_appendix`, which executes only the tagged new cells and preserves every earlier cell.
