# Zenodo

The Zenodo MTS archive (1,053 series): run pyspi over it, build a unified SPI–SPI representation, embeddings and stable clusters. It may become the prior over which a minimal feature set is selected.

- `atlas/`: corpus configs and index lists, the atlas fit (`run_atlas_analysis.py`), corpus geometry (`run_corpus_geometry.py`), catch22 comparison, exploration and gallery scripts.
- `shared/`: the atlas fitting module.

Context: [`docs/context/zenodo-mts-corpus.md`](../../docs/context/zenodo-mts-corpus.md).
