Methods, interpretation and files

Primary: ≥95% finite features, median imputation, drop near-constant features, mean centring; no feature z-scoring or PCA whitening. 21,788 retained features. “Full” clustering uses exact full-rank PCA coordinates whose corpus Euclidean distances were checked against all retained features; it is not truncated PCA.

Historical p10 coordinates and memberships are preserved from v1. Other perplexities are explicitly variations. Optional K-medoids k200 uses a NumPy compatibility implementation of heuristic initialization / alternate updates, not the unavailable original binary.

Feature-space partitions stay fixed when the embedding changes. Map-region partitions are precomputed for their named map; changing the map never silently refits them. Default map-region choices correspond to the displayed map; enable the comparison checkbox to inspect mismatches.

Silhouettes and representative medoids use the full primary geometry. HDBSCAN silhouettes cover assigned rows only; do not rank them against full-coverage K-means without accounting for coverage. Seed ARI measures K-means initialization sensitivity, not resampling stability. Parent recordings/nested windows are not independent replicates.

Heatmaps: each process is centred by its temporal median and scaled by IQR/1.349, then clipped symmetrically at the per-MTS 99th percentile of absolute values. Widths are normalized for browsing; original M×T is shown. Colours are not absolute amplitude comparisons. SVG heatmaps contain the native raster.

Origin annotations use archive tags plus documented local corrections: HCP task-state and resting-state fMRI are real recordings. The source archive and feature bank are unchanged. The historical plotting scripts hid HDBSCAN label −1 before drawing; this explorer deliberately retains those unassigned datasets.
